The conformity assessment procedure itself is not part of this review. It is managed as its own task, usually on the topmost project level, and the EU CRA module provides it. This check only confirms that it has been carried out and that its evidence exists for this release.

Mark this check as not applicable if the product is not placed on the EU market.

Check that

* The applicable EU conformity assessment procedure has been carried out
* The conformity assessment has been revisited if this release changes the design or the characteristics of the product in a way that affects conformity
* The evidence of the assessment, including the EU declaration of conformity, has been archived with the other release artifacts

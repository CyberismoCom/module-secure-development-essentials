[TIP]
====
A group organises the elements of a dataflow model in the navigation tree and arranges the diagrams. It is not an asset and not a trust boundary.

When _Show in diagrams_ is set, the group is drawn as a grey rectangle with its title around its elements. Clear it if the group only organises the navigation tree. A hidden group still keeps its elements together when the diagram layout of the model is _Follow the dataflows_.

When the diagram layout of the model is _Zones in tree order_, a group that contains zones is one row of the diagram, and its zones are drawn side by side in tree order.

Use a trust boundary instead, if crossing the boundary changes the level of trust, and a process, if the group is a real system with an owner.

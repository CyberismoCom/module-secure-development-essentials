== Introduction

This is a review of the use of cryptography in a development project to ensure that cryptography is used properly and effectively.

== Use cases for cryptography

Each use case of cryptography is one item in the checklist below. Open an item to give the use case a name and to describe it. To add a use case, click "Add a checklist item".

NOTE: Notice that the use of cryptography must be planned in the light of the expected usage period. Select such algorithms and key lengths that are expected to be applicable during the usage period and as new technologies such as quantum computing become available.

Set the result of each item in the table. A Deviation or Not applicable result needs a comment. Put links to the evidence in the comment.

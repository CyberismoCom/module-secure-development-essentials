[TIP] 
====
Create a risk if you identify a cyber threat — something that can cause harm by exploiting one or more vulnerabilities. A risk is the potential for loss: how likely a threat is to exploit a vulnerability, and how severe the resulting harm would be.

If the risk affects a certain element of the threat model or a certain asset, then you can create the risk within the affected card. 
====

Add risks that cannot be created in the threat model or in one of the assets by clicking the following button.
